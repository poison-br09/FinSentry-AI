### ✅ **What Ollama *Can* Do (with right setup):**

If you’re running a **local LLM** (like LLaMA, Mistral, or similar) using Ollama with proper tooling, then:

1. **You can load a PDF** (using tools like `PyMuPDF`, `pdfplumber`, or `pdfminer`) to extract text.
2. **You can prompt the LLM** to classify transactions into categories using regex or keyword matching.
3. **With custom scripts**, you can:

   * Parse structured fields (`Date`, `DR`, `CR`, etc.)
   * Classify based on keywords.
   * Export to `CSV`, `JSON`, or even build a report.

---

### ❌ **What Ollama *Can’t* Do Out-of-the-Box:**

* **Doesn't support PDFs natively** — you need a Python script to extract PDF content first.
* **No memory or advanced chaining** — unlike ChatGPT with tools or LangChain, you need to manage context, chunking, and logic manually.
* **Model limitation** — smaller models like `llama2:7b` might struggle with:

  * Long document context (token limit)
  * Complex reasoning or fuzzy classification
  * Producing clean structured JSON reliably
